# COMPAS Dataset

This project uses the COMPAS two-year recidivism dataset in `compas-scores-two-years.csv` as a benchmark for fairness-aware synthetic tabular data generation. The data contains demographic information, age, juvenile and prior-offense counts, charge details, and recidivism outcomes.

## Selected features

The modeling dataset was created by selecting the following fields:

For people without a recorded recidivism event (`is_recid == 0`), the rearrest charge fields are set to `Not applicable` rather than left ambiguously missing.
